# УУСТ Журнал

Неофициальное мобильное приложение для электронного журнала УУСТ (Училище / колледж). Показывает расписание, оценки, задания и напоминает о парах. Работает на iOS и Android как обычное standalone-приложение — **без Expo Go, без Mac и без платного аккаунта разработчика Apple**.

- **Репозиторий:** https://github.com/Exile37/uust-jornal
- **Версия:** 1.2.0
- **Bundle ID / package:** `com.exile37.uustjournal`

## Возможности

| Раздел | Что делает |
|---|---|
| **Вход** | Авторизация в журнале УУСТ, вход по биометрии (Face ID / отпечаток) |
| **Главная** | Ближайшая пара, расписание на сегодня, статистика оценок, счётчик задач |
| **Оценки** | Список предметов с оценками и подробности по каждому предмету |
| **Расписание** | Пары по дням, кабинет, преподаватель, общий доступ расписанием |
| **Задачи** | Свои задачи: предмет, дедлайн, напоминание в 9:00, завершение и удаление |
| **Настройки** | Группа, биометрия, кэш, уведомления, интервал напоминаний, версия |

### Уведомления

- Напоминания о парах (за 5 / 10 / 30 / 60 минут — настраивается).
- Оповещения о новых оценках.
- Бейдж с числом непросмотренных оценок на иконке приложения.
- Офлайн-кэш: расписание и оценки доступны без сети (баннер офлайна).

### Обратный отсчёт до пары

За 5 минут до начала пары появляется живой таймер (`MM:SS`), который обновляется каждую секунду. Показывается на экранах «Главная» и «Расписание», включается кнопкой в шапке расписания (состояние сохраняется).

## Как установить на телефон

Приложение ставится **сайдлоадом** (sideload). Аккаунт разработчика и магазины приложений не нужны.

### Android (проще всего)

1. Открой сборку **Build Android APK** в разделе Actions репозитория (последняя зелёная).
2. Внизу страницы, в блоке **Artifacts**, скачай `uust-journal-android-apk`.
3. Распакуй архив — внутри `app-release.apk`. Перекинь файл на телефон (или скачай сразу с телефона).
4. Открой APK на телефоне. Android спросит разрешение на установку из неизвестного источника — разреши для файлового менеджера / браузера.
5. Нажми **Установить**.

APK подписан debug-ключом, поэтому ставится на любое устройство без дополнительных действий.

### iOS (iPhone / iPad)

1. Открой сборку **Build unsigned iOS IPA** в разделе Actions.
2. Внизу, в **Artifacts**, скачай `uust-journal-unsigned-ipa`.
3. Распакуй архив — внутри `uust-journal-unsigned.ipa`.
4. Установи IPA на iPhone одним из способов:
   - **Sideloadly** (Windows/Mac) — нужен Apple ID (бесплатный подойдёт).
   - **AltStore / SideStore** — приложение-установщик прямо на телефоне.
   - **TrollStore** — если устройство поддерживает.

> Приложения, подписанные бесплатным Apple ID, действуют **7 дней**, после чего их нужно переустановить. Это ограничение Apple, а не приложения.

```
│   │   ├── GradesScreen.js             # Оценки по предмету
│   │   ├── ScheduleScreen.js           # Расписание
│   │   ├── TasksScreen.js              # Задачи
│   │   └── SettingsScreen.js           # Настройки
│   └── services/
│       ├── authService.js              # Логин/выход, биометрия, прокси
│       ├── cacheService.js             # Офлайн-кэш
│       ├── notificationService.js      # Локальные уведомления

│       ├── subjectsService.js          # Предметы и оценки
│       └── tasksService.js             # Задачи

    └── android-build.yml               # Сборка release APK
```

### Backend

Приложение **без собственного сервера**. Данные берутся с сайта журнала через прокси. Адрес прокси задаётся в `src/services/authService.js`:

```js
export const PROXY_URL = 'https://uust-proxy.onrender.com';
```

`proxy.py` — Flask-приложение, повторяющее маршруты журнала (`/api/login`, `/api/subjects`, `/api/grades` и т.д.). Его можно развернуть на своём сервере и заменить `PROXY_URL` на свой адрес.

## Локальная разработка

### Требования

- Node.js 20+ (в CI используется 24)
- npm

### Запуск

```bash
# Установить зависимости
npm install

# Запустить dev-сервер Expo
npm start
# или напрямую:
npx expo start
```

После запуска открой проект в приложении **Expo Go** на телефоне или в эмуляторе (команды `a` / `i` в терминале).

> Expo Go подходит только для разработки. Готовое standalone-приложение собирается отдельно (см. ниже).

### Полезно

```bash
# Проверить, что JS-бандл собирается
npx expo export --platform ios

# Сгенерировать нативные проекты (ios/ и android/)
npx expo prebuild --platform ios     --no-install --clean
npx expo prebuild --platform android --no-install --clean
```

Каталоги `ios/` и `android/` генерируются автоматически и не хранятся в репозитории.

## Сборка приложения

### Android — локально

Нужны JDK 17 и Android SDK (platform 36, build-tools 36.0.0).

```bash
# 1. Сгенерировать нативный проект
npx expo prebuild --platform android --no-install --clean

# 2. Указать путь к Android SDK
echo "sdk.dir=$ANDROID_HOME" > android/local.properties

# 3. Собрать release-APK (подписывается debug-ключом)
cd android
./gradlew assembleRelease
```

Готовый файл: `android/app/build/outputs/apk/release/app-release.apk`.

### iOS — локально

Требуется **macOS с Xcode**. На Windows/Linux собрать iOS-приложение нельзя — используйте [GitHub Actions](#автоматическая-сборка-github-actions).

```bash
npx expo prebuild --platform ios --no-install --clean
cd ios && pod install --repo-update
xcodebuild -workspace uustapp.xcworkspace -scheme uustapp \
  -configuration Release -sdk iphoneos \
  CODE_SIGN_IDENTITY="" CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO build
```

## Автоматическая сборка (GitHub Actions)

Сборки запускаются автоматически при пуше изменений в `App.js`, `app.json`, `src/**`, `assets/**` или сами воркфлоу. Также можно запустить вручную: **Actions → выбрать воркфлоу → Run workflow**.

| Воркфлоу | Результат | Артефакт |
|---|---|---|
| `ios-build.yml` | Unsigned IPA | `uust-journal-unsigned-ipa` |
| `android-build.yml` | Подписанный release APK | `uust-journal-android-apk` |

Артефакты хранятся 30 дней. Скачать можно со страницы запуска в блоке **Artifacts**.

> Так как APK подписывается debug-ключом, установка новых версий «поверх» старой может потребовать удаления приложения. Для нормальных обновлений нужен свой release-keystore.

## Разрешения и уведомления

| Платформа | Разрешения |
|---|---|
| iOS | Уведомления, Face ID (`NSFaceIDUsageDescription`) |
| Android | `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED`, `SCHEDULE_EXACT_ALARM`, `VIBRATE`, биометрия |

На Android 13+ система отдельно спросит разрешение на уведомления при первом запуске. Разрешение `SCHEDULE_EXACT_ALARM` нужно, чтобы напоминания о парах срабатывали точно по времени.

## Ограничения бесплатного аккаунта Apple

При сайдлоаде с бесплатным Apple ID недоступны:

- **Виджеты** (Widget Extension) — нужен платный аккаунт.
- **Dynamic Island / Live Activities** — нужны App Groups и Live Activity entitlement.
- **App Groups** и push-уведомления с сервера (APS).

Всё остальное — расписание, оценки, задачи, локальные уведомления, таймер до пары — работает без ограничений.

## Решение проблем

**Уведомления не приходят**
Проверь разрешение: Настройки → Уведомления → приложение. На Android 13+ нужно явно разрешить уведомления. Отключи экономию батареи для приложения, она может блокировать точные напоминания.

**Не входит в аккаунт / пустые данные**
Проверь интернет и доступность прокси (`PROXY_URL`). Если прокси на бесплатном хостинге, первый запрос может быть медленным — он «просыпается».

**Android: «Приложение не установлено»**
Удали предыдущую версию и установи APK заново (подпись может отличаться), либо разреши установку из неизвестных источников.

**iOS: приложение перестало открываться через 7 дней**
Срок подписи бесплатным Apple ID истёк — переустанови IPA через Sideloadly / AltStore.

**iOS-сборка упала в CI**
Обычно из-за новой версии Xcode. Воркфлоу сам выбирает самый новый установленный Xcode; если проблема сохраняется — см. лог шага Build.
