# УУСТР Журнал 1.4.1

Что изменилось:
- нижняя панель получила рисованные иконки: домик, журнал, зачётка, сетка недели, ползунки. Иконки нарисованы из обычных линий, поэтому новых зависимостей нет;
- активная вкладка отмечается цветом иконки, подписи и короткой чертой сверху; линейка остаётся единственным цветным пятном;
- при очень крупном системном шрифте подпись остаётся только у активной вкладки — тогда пять названий не наезжают друг на друга;
- оформление 1.4.0 сохранено: тёплая тёмная шкала «бумага и чернила», один янтарный акцент, тонкие линии вместо цветных коробок;
- версия приложения повышена до 1.4.1.

## Уведомления
Интерфейс настроек напоминаний уже подготовлен. Для реальных системных уведомлений нужно отдельно установить совместимую версию `expo-notifications` для Expo SDK 54 и подключить `src/services/notificationService.js`. В текущей сборке зависимость намеренно не добавлена, чтобы проект запускался без дополнительного пакета.
