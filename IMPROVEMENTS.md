# УУСТР Журнал 1.4.0

Что изменилось:
- новое оформление: тёмная шкала «бумага и чернила», один тёплый акцент, тонкие линии вместо цветных коробок;
- лента расписания: дни подряд, сегодняшний день отмечен, тип пары — точкой, кабинет и преподаватель — строкой метаданных;
- зачётка: официальная выписка из личного кабинета (`StatementStudents/Index`), оценки-штампы, группировка по семестрам, рейтинг;
- «Главная»: ближайшая пара, средний балл, предметы и расписание на сегодня без лишних карточек;
- единая полоса статистики и общие списки с разделителями на всех экранах;
- таймауты на все запросы: вместо бесконечного спиннера — понятная ошибка;
- офлайн-кэш зачётки; оценки журнала не подставляются вместо официальных;
- версия приложения повышена до 1.4.0.

## Уведомления
Интерфейс настроек напоминаний уже подготовлен. Для реальных системных уведомлений нужно отдельно установить совместимую версию `expo-notifications` для Expo SDK 54 и подключить `src/services/notificationService.js`. В текущей сборке зависимость намеренно не добавлена, чтобы проект запускался без дополнительного пакета.
