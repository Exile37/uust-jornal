# УУСТР Журнал 1.1.0

Что добавлено:
- новый Dashboard с ближайшей парой, расписанием на сегодня и статистикой;
- 4-tab навигация: Главная / Оценки / Расписание / Настройки;
- поиск по предметам и преподавателям;
- обновлённые карточки и состояния пустого списка;
- статистика среднего балла и количества оценок на главной;
- экран настроек: группа, биометрия, кэш и параметры напоминаний;
- более аккуратная нижняя навигация и UI;
- сохранение выбранной группы и офлайн-кэш сохранены;
- версия приложения повышена до 1.1.0.

## Уведомления
Интерфейс настроек напоминаний уже подготовлен. Для реальных системных уведомлений нужно отдельно установить совместимую версию `expo-notifications` для Expo SDK 54 и подключить `src/services/notificationService.js`. В текущей сборке зависимость намеренно не добавлена, чтобы проект запускался без дополнительного пакета.
